# 这个项目究竟要做一颗什么芯片？

这是一个面向低频差分传感器的“可编程模拟前端＋模数转换器”芯片核心，采用 SKY130 工艺。它的工作，是把传感器产生的小电压差转换成计算机能处理的数字。运算放大器只是其中一个模块，不再是项目的全部。

信号路径是：**外部传感器的差分电压 → 1／4／16 倍可编程放大 → 采样与 12-bit SAR ADC → 原始数字码 → 外部软件校准。**

## 1. 为什么需要它？

例如，一个合适的外部压力或应变传感器已经把物理变化变成两根线之间的小电压差。电脑不能直接准确理解这个电压：信号可能太小，还会有电路偏差和噪声。本芯片核心负责放大、采样和数字化。

芯片内不包含压力膜片、应变片等感应元件，也不提供桥式激励。把数字电压进一步换算成牛顿、帕斯卡或其他物理量，还需要外部传感器自己的转换关系和标定。

## 2. 里面各部分做什么？

| 模块 | 通俗解释 | 真正需要设计的东西 |
|---|---|---|
| 差分可编程前端 | 根据传感器信号大小选择放大倍率 | 晶体管放大器、电阻反馈、增益开关、共模反馈、偏置和启动 |
| 采样电路 | 在指定时刻把电压暂时记住 | MOS 开关、储存电荷的电容、非重叠时序和采样驱动 |
| 电容 DAC | 产生 ADC 用来比较的候选电压 | 二进制加权 MIM 电容、参考切换、寄生与匹配布局 |
| 比较器 | 回答“输入比当前候选值大还是小” | 放大／再生、保持输出、失调、噪声和回踢控制 |
| SAR 数字控制 | 连续问 12 次大小问题，逐位确定结果 | 可综合 Verilog、握手／复位／增益锁存、标准单元物理实现 |
| 外部校准软件 | 校正固定的零点和比例偏差 | 每档增益的固定线性系数、独立验证和原始数据保留 |

“共模反馈”控制两根输出线的平均电压，避免整体漂移到电源边缘；“偏置”给晶体管设置合适的工作电流；“启动电路”防止偏置电路上电后停在不工作的状态。它们和信号放大本身一样，是芯片能否工作的组成部分。

## 3. 一个具体例子

假设传感器两端都在 0.9 V 左右，但正端比负端高 1 mV。选择 16 倍增益，目标 ADC 输入差分电压就是 16 mV。

ADC 的目标范围是 −0.4～+0.4 V，一共分成 4096 个码，每格约 195.3125 µV。因此零差分附近是中间码 2048，16 mV 对应约 2130 码。外部软件再用保存的该档增益系数校正零点和比例误差。

这只是解释目标传递关系的理想例子，不是对实际芯片误差、噪声或分辨能力的承诺。12-bit 输出也不等于真的有 12-bit 有效精度；本项目的标称实际精度目标是约 10.5 ENOB。

16 倍档的传感器满量程为 ±25 mV，4 倍档为 ±100 mV，1 倍档为 ±400 mV。信号太大仍会过载，软件校准不能把已经丢失的信息恢复出来。

1 倍档并不是“什么都没做”。它服务于本来就较大的传感器信号，避免 4 倍或 16 倍把前端、采样器或 ADC 推到饱和；同时仍完成差分驱动、共模控制、隔离和低阻抗驱动真实采样电容。三档合在一起的意义，是让同一颗芯片既能看很小的信号，也能接较大的信号，而不是为了让 1 倍档看起来有额外电压增益。

## 4. 要达到的性能——目前仍是目标

- 输入信号带宽 DC–5 kHz，每秒输出 100,000 次结果。
- 外部时钟 1.6 MHz；每次转换 16 个周期，4 个用于采集，12 个用于逐位判决。
- 电源标称 1.8 V，并验证 1.62／1.80／1.98 V、−20／27／85 °C 和五个工艺角。
- ADC 差分满量程 0.8 Vpp、12-bit 偏移二进制原始码。
- 全链路 SNDR 标称至少 65 dB、规定工艺温压组合至少 62 dB；核心功耗标称至多 2 mW、组合条件至多 3 mW。
- 默认传感器每端源阻抗 350 Ω；还检查 0 Ω、1 kΩ 和 ±50 mV 输入共模偏离。

完整定义仍以 [冻结规格](../config/spec.json) 和原计划为准。任何模块的几个通过点，都不能替代这些整体验收条件。

## 5. 哪些在芯片里，哪些在外面？

芯片核心内：前端、偏置和启动、采样开关、电容 DAC、比较器、相位电路、SAR 控制逻辑。

芯片外：传感器、供电、参考电压与共模电压、时钟源、接收并行数据的设备，以及运行校准程序的电脑或微控制器。标称参考电压为 0.7／1.1 V，共模参考为 0.9 V。仿真必须注明这些源的阻抗和外部去耦，不能假定参考有无限驱动能力。

首版没有 SPI、处理器、自动增益控制、片上自校准、完整抗混叠滤波器，也没有流片、焊盘／ESD、封装或测试板。外部输入必须满足带宽与电平条件。

## 6. 当前成果应该怎样称呼？

当前是“SKY130 传感器读出芯片核心的设计与分模块验证项目”。已经有真实器件电路、数字控制版图和短时整链路转换，不再只有一个理想模型；但完整芯片仍未通过全部精度、温压、失配和顶层寄生验收。

最终还要在 Cadence 中完成原生原理图、完整核心版图、DRC/LVS、寄生提取和同条件后仿真。没有制造和实际测量之前，不能称作已流片或硅测芯片。最新完成情况与失败见 [实施状态](status.md)。
