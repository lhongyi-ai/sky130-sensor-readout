# 完整晶体管前端的原生闭环极点审计

## 结果：完成两次有界尝试，但不能用于稳定性验收

固定源文件为 `../results/20260910T062811944809Z_cascoded_tail_g16/candidate.spice`，SHA256：

`564f4776c4c61872de63648816ef5aaf51555769edeca326042f287880ae1a3c`

在 ngspice 47 中，增益 1 和 16 各运行一次原生 `.pz`，没有重新设计或删除电路中的器件。每次限 120 秒，均在秒级完成。**当前审计结论以 [qualification.json](qualification.json) 为准，不把原始返回的根列表自动当作真实电路极点。**

| 标称配置 | 原生输出根数 | 其中正实部条目 | 非有限进度值 |
|---|---:|---:|---|
| G=1 | 649 | 245 | 日志出现 `Reference value: nan` |
| G=16 | 668 | 614 | 日志出现 `Reference value: nan` |

这些是**原生算法报告的条目数**，不是已经证实的物理右半平面极点数量。大量根及非有限进度值是需核实的数值异常线索，不足以仅凭它们断言电路存在数百个真实不稳定模式；同样不能把它们直接扔掉后宣称电路稳定。

[ngspice 官方手册](https://ngspice.sourceforge.io/docs/ngspice-manual.pdf) 1.2.4 节明确说明：PZ 使用数值搜索，在较大电路中可能找不齐根，也可能返回过多根。此处没有进行各根残差、线性系统特征向量、条件数或独立算法复核，因此最终状态为：

`NATIVE_CLOSED_LOOP_PZ_ATTEMPT_COMPLETE_NUMERICAL_QUALIFICATION_INCOMPLETE`

## 电路和测量口径

- TT、1.8 V、27 °C，输入差分零、共模 0.9 V。
- 传感器每端源电阻 350 Ω。
- 使用原完整晶体管电路、真实偏置和共模反馈，不切断任何反馈环路。
- 每端隔离电阻使用 PDK `frontend_r R=2600`。
- 每端 4 pF 滤波电容使用原 PDK MIM 辅助电路。
- 每端 ADC 静态负载由 4096 个 3×3 µm MIM 单元的同构 `m=4096 mult=4096` 表示，标称 81.28512 pF；不是删掉负载或换成小电容。
- 采用 `pz fp 0 fp 0 cur pol`：从单侧输出注入小信号电流、观察同一端口电压，测量闭环驱动点阻抗的极点。该非对称端口一般能同时耦合差模和共模，比只观察对称差分输出更不容易漏掉完全对称的共模动态。
- 但单一输入／输出端口仍不能保证所有内部偏置状态、共模状态均可控、可观测；极零相消、退化状态及数值根搜索问题仍须单列。

真实采样开关在这里没有切换；它是采集阶段大电容静态负载的闭环小信号试验，**不能代替采样／保持切换负载瞬态，也不能代替大信号、电源启动或PVT验证。**
