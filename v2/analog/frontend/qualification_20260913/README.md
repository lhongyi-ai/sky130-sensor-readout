### 旧高频上穿越主要是测量方法问题

旧电压比忽略了反向传输和测量口的负载。本轮在正常直流连接中加入零直流电压源及零直流电流源，以两次 AC 激励求局部双向返回比；其他真实回路保持闭合。六种增益/开关状态中，旧差模在约 38.9–74.8 MHz 的第二次 0 dB 上穿越全部消失。

| 状态 | G1 差模局部 PM | G4 差模局部 PM | G16 差模局部 PM |
|---|---:|---:|---:|
| 采集开关固定导通 | 81.79° | 81.91° | 81.96° |
| 采集开关固定关断 | 74.22° | 81.21° | 87.33° |

这是局部回路诊断。G1/G4 的第一级共模低频返回符号异常仍在，不能将本表或独立回路 PM 当作完整多环签核。

双注入公式采用 [Tian 等人的原始论文](https://kenkundert.com/docs/cd2001-01.pdf) 中双向两端口分析；该方法有适用条件。这里没有找到能切断全部反馈的单一关键导线，因此不把单探针结果提升为全局证明。

### 耦合返回差已经算出，正式签核仍有明确缺口

四个测量平面为差模输入、共模输入、第一级共模、输出共模。分别施加电流/电压激励，保存完整 A/B/C/D 交叉响应，重建端口导纳 K，并计算 `det(K)/det(Yee+Yff)`。原始矩阵在每组 `coupled_hybrid_matrices.npz`，返回差曲线在 `coupled_return_difference.csv`。

六组矩阵重建代数残差最大约 2.09e−16，C 矩阵条件数最大约 5021。这个残差只检查矩阵代数重建，**不是原始晶体管 Jacobian 的特征根残差**。参考导纳仍含有源器件，尚无可靠的右半平面极点计数；内部不可观测模态未排除，1 GHz 端点也不能自动替代无限频率轮廓。未声明 Nyquist 绕数或全局 PM 通过。

### 同源静态噪声揭示了实际设计压力

下表为 **1 Hz–1 GHz，FP−FN 输出端，乘同源三点校准斜率后** 的连续时间小信号噪声。开关在各状态固定，不含周期切换、噪声折叠或真实 ADC 转换噪声。

| 固定状态 | G1 | G4 | G16 |
|---|---:|---:|---:|
| 采集态 | 71.43 µVrms | 151.17 µVrms | 431.74 µVrms |
| 保持态 | 128.07 µVrms | 243.77 µVrms | 536.06 µVrms |

113 µV 来自旧 `build_frozen_summary.py` 的暂定静态输出预算，其旧 FDDA10 隔离电阻为 2.8 kΩ。本轮是电阻输入 PGA、1.5 kΩ 隔离、明确固定的采样状态，测试装配不相同。因此本表与 113 µV 只作诊断比较，正式噪声 PASS/FAIL 留空，不能用来宣布系统 65 dB SNDR 合格或不合格。1–5 kHz 与 1–50 kHz 积分也完整保存，但不能用截窄带宽替代宽带/采样噪声验收。

首次 6 次 noise 在正确完成求解后，因读取错误的当前 plot 而报 `no such vector onoise_spectrum`。六份原始失败和 exit code=0 均保留，分析状态仍是失败；改为显式选择 `noise1` 后原刺激重跑成功。运行器现已遇同类失败立即停止。不能仅凭进程退出 0 宣称结果导出成功。

### 完整闭环 PZ 尚不能作为证据

G1 采集态原生 `pz fp 0 fp 0 cur pol` 正常退出，返回 354 个根，其中 239 个被算法标为右半平面。根列数量、分布和已有稳定瞬态之间存在需要解释的矛盾，未完成残差、阶数和模态完整性审计。原始根列原封不动保存；既不凭这些未经验证的根宣布真实失稳，也不删掉它们后宣称稳定。[ngspice 官方手册](https://ngspice.sourceforge.io/docs/ngspice-42-manual.pdf) 说明该搜索方法可能漏根或返回过多根。没有因无新依据而继续换端口反复重试。
