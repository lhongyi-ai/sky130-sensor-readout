# SKY130 ADC analog implementation — development evidence

This directory contains an ADC analog circuit built from actual SKY130 MOS devices, resistors, and MIM capacitors, not a behavioral ADC. It remains a **transistor-level design that has not completed specification qualification**; there are no native Cadence schematics, complete ADC layout, or silicon measurements. Project-level completion is governed by `v2/integration` and the top-level audit. Passing independent modules in this directory cannot be added together to claim a full-chip pass.

## Circuit and scope

`adc_blocks.spice` provides MOS transmission gates, a StrongARM dynamic comparator, a static CMOS decision-holding latch, reference-selection logic, real MIM cells, and a conventional 12-bit binary CDAC. The holding latch retains Q while the dynamic comparator resets, meeting the hold requirement after sampling by the real digital controller.

Each side contains 2048+1024+…+1 capacitors plus one dummy, totaling 4096 cells of 3×3 µm. The installed continuous PDK model includes a 0.15 µm dimensional correction on each side, giving a nominal unit capacitance of 19.845 fF and 81.28512 pF per side. `m=COUNT` implements the nominal parallel count; `mult=COUNT` correctly scales the model mismatch standard deviation with the unit count. Setting only `m` does not establish correct statistical matching. These semantics have been independently verified by environment qualification tests. The 73728 µm² for 8192 basic cells is only the nominal electrode area, never the complete core layout area.

Four independent top levels are generated by `generate_analog_wrapper.py`:

| File / subckt | Purpose | Current selection status |
| --- | --- | --- |
| `adc_analog12.spice` / `adc_analog12` | Top-plate sampling, reference bottom-plate switching, direct comparator | Retained baseline for the first complete conversion |
| `adc_analog12_bottomsample.spice` / `adc_analog12_bottomsample` | Top plates clamped to VCM; input sampled on bottom plates | Independent control; switching interference still causes failures with the unbuffered comparator |
| `adc_analog12_bottom_preamp.spice` / `adc_analog12_bottom_preamp` | Bottom-plate sampling followed by a real continuous-time preamplifier to isolate the comparator | Candidate; also requires `adc_preamp.spice` |
| `adc_analog12_bottom_preamp_lvtref.spice` / `adc_analog12_bottom_preamp_lvtref` | Preamplifier plus dual-LVT acquisition/reference TGs sized by bit weight | Settling-repair candidate; also requires `adc_reference_candidate.spice`; top-plate clamp TGs remain standard-Vt |

Common port order:

```text
INP INN Q QB SAMPLE SAMPLEB ACQ CONV EVAL
B11 B10 B9 B8 B7 B6 B5 B4 B3 B2 B1 B0 RP RN VCM VDD VSS
```

`SAMPLE/SAMPLEB` first enables the top-plate input/clamp path; `ACQ` then enables bottom-plate acquisition; after the nonoverlap interval, `CONV` connects the bottom-plate references; after residue settling, `EVAL` triggers comparison. A high Q means the differential input exceeds the current trial threshold. External phases in fixed-code tests are ideal finite-edge stimuli, not on-chip clock circuits. The real MOS phase generator and original RTL closed loop are separately verified in `v2/integration`.

The offset-binary threshold is `0.8*code/4096 - 0.4 V`. The dummy cannot be arbitrarily connected to VCM: in top-plate sampling, the P dummy connects to RP and the N dummy to RN; bottom-plate sampling reverses those connections and the comparator polarity to retain the same threshold definition. An early incorrect dummy connection caused an approximately 1 LSB global shift. That failure has been retained and was not hidden by calibration.

`adc_preamp.spice` is an independent candidate and does not replace the original comparator: it uses a real NMOS differential pair, 75 kΩ PDK polysilicon resistor loads, beta-multiplier bias, and a startup circuit, with no ideal IREF. Its purpose is to reduce dynamic-latch kickback into the floating CDAC. Preamplifier noise, offset, and large-signal recovery must still be included in the budget.

The reference-switch subcircuit defaults to WN0.84/WP1.68, but the actual wrapper already scales width with the square root of bit weight, capped at WN8/WP16 for the highest bits; **the MSB does not use the small default size**. The minimum-switch-driving-MSB test in `run_reference_switch.py` is only a sizing counterexample, and its failure cannot be attributed to the frozen MSB. Use `--actual-only` for the actual MSB comparison. The new dual-LVT branch is stored separately in `adc_reference_candidate.spice` and has not replaced the frozen circuit without authorization.

Reference diagnostics default to `--reference-mode fixed`, keeping RP/RN at 1.1/0.7 V while the input common mode still tracks VDD/2. In `tracking` mode, RP/RN=VDD/2±0.2 V, becoming 1.01/0.61 V at low supply. These external conditions must not be conflated; fixed-reference errors cannot directly explain whole-ADC results obtained with tracking references. The original specification gives only nominal references. The final external-reference rule must be explicitly frozen, or both modes must be covered.

In the actual SS low-voltage cold-corner comparison with tracking references, the W8/P16 standard-Vt MSB branch driving a 20.321 pF equivalent load still had a −124.56 mV error 300 ns after switching from 0.61→1.01 V. Under the same conditions, the W13.44/P26.88, LN0.15/LP0.35 dual-LVT candidate reduced the error to −0.000584 µV. Here 20.321 pF is the series-equivalent lower bound for a floating MSB, and 40.643 pF is the upper acquisition-load bound with the top plate clamped; both use real MIM instances. Load-boundary experiments do not replace qualification of the full array's phase-dependent load, injection, mismatch, parasitics, and noise.

## Verified results and conclusions they do not support

- Bare comparator: correct results for 45 PVT combinations × both ±0.25 LSB inputs, plus 10 TT input-amplitude points. The input remains driven by a 350 Ω source; **these are not floating-CDAC conditions**.
- Comparator holding interface: six conditions, each with two opposite decisions and a 5 fF digital load. The longest measured resolution time is approximately 8.23 ns, and the output remains held after reset. This does not establish full-PVT timing signoff.
- Original standard-Vt sampling TG: 51 nominal points passed, but subsequent independent physical tests found severe settling failure at the SS low-voltage cold corner. The TG has not obtained PVT qualification. The new low-threshold input TG and its layout are being developed separately in `v2/physical/adc_switch`; they cannot directly replace the small reference switches.
- CDAC: 17 nominal code points and all-code charge-conservation calculations for 200 pairs of real PDK statistical capacitor arrays. Statistics cover capacitor mismatch only, excluding the comparator, switches, frontend, wiring, and spatial gradients; **they do not represent 200 ADCs or production yield**.
- Comparator: 200 real `tt_mm` instances and 1400 coarse threshold decisions. The initial ±3 mV range bracketed only 143 instances, with 57 outside the range. Later runs expanded and refined the range. Original failures and near-threshold history dependence are retained; fixed-calibration results and finite estimation precision are governed by the corresponding JSON.
- Six-point floating-CDAC comparison: bottom-plate sampling itself improves the precomparison residue, but 3/6 decisions remain incorrect without a preamp; adding the actual preamp under the same reference conditions gives 6/6 correct. This is an engineering improvement in module interaction, **not proof of all-code no-missing-code performance or 12-bit accuracy**.

For bit-by-bit control of the complete real SAR, read `v2/integration/results`: it uses the original `SAR RTL` in a live digital/SPICE closed loop, not correct codes generated in advance or afterward from the ideal input. The early B-source register attempt in this directory's `run_sar_transistor.py` encountered convergence/timeouts. It has been superseded by that workflow and cannot serve as a successful qualification entry point.

## Reproduction entry points

In the fixed IIC container, set `SPICE_USERINIT_DIR=/foss/pdks/sky130A/libs.tech/ngspice` and run the scripts below as needed. Start only one heavy simulation worker at a time in the shared container.

```sh
python3 /repo/v2/analog/adc/run_adc.py --suite full --jobs 1
python3 /repo/v2/analog/adc/run_latch_interface.py
python3 /repo/v2/analog/adc/run_cdac_mismatch.py
python3 /repo/v2/analog/adc/run_comparator_mismatch.py
python3 /repo/v2/analog/adc/run_analog_wrapper.py --architecture bottom_preamp --reference-ohm 1 --external-reference-cap-f 1e-8
python3 /repo/v2/analog/adc/run_preamp.py --jobs 1 --resume
python3 /repo/v2/analog/adc/run_preamp_pvt.py --jobs 1 --resume
python3 /repo/v2/analog/adc/build_summary.py
```

`generated/` stores actual SPICE testbenches; `results/` stores logs, waveforms, and JSON; `results/history/` preserves failures and the history of revised tests. New simulations save per-run source hashes and source snapshots. `summary.json` is a qualification index with explicit scope, and `manifest.json` is a file-hash manifest. Current source hashes do not stand in for the source hashes used by every historical test.

## Risks that must remain explicit

There is no complete-ADC all-code transistor-level INL/DNL, 16384-point SNDR with real device noise, complete 200-run system mismatch study, full ADC layout/PEX, or Cadence verification. Continuous-time preamp `.noise` establishes only its local static small-signal noise. Referring the output spectrum through DC gain differs from directly integrating the input-referred spectrum; both are reported separately. A noiseless transient FFT, a kT/C formula, or an artificial white-noise source cannot be presented as device-noise verification of the time-varying comparator.

The comparator input pair exhibited a real asymmetry when the installed PDK/ngspice applied different corner models to literal widths and expression widths. An independent same-voltage transistor-current comparison confirmed that matching expressions on both legs restored matching. Merely changing parameter names or avoiding the 8 µm boundary did not fix it; these disproven hypotheses have been retained. An unverified internal cause is not presented as a conclusion.
