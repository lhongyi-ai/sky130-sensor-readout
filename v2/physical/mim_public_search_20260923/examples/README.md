# Public MIM examples and independent-reference limits

The bounded source review found nine official measured MIM C–V files and a JKU archived MIM delay cell with layout, schematic, extracted device netlist and LVS/timing records. These are useful partial references, not a complete independent current-CAPM peripheral RC calibration.

Each measured dataset has661 voltage points; square, long-rectangular and stacked arrays are represented. Matched physical geometry, measurement temperature/frequency, de-embedding, uncertainty and fit/holdout relation were not established. Functional C–V data alone cannot validate neighbor/substrate multiport coupling.

The examined JKU postlayout file contains no explicit complete peripheral RC reference; model-placeholder and scaling warnings require review. Homogeneous-dielectric numerical field-solver comparisons validate algorithms under their assumptions, not missing CAPM material data. A linked alternative testtile source was inaccessible, so it was not assumed to match the measured wafer structures.

No downloaded code, field solve, simulation or school operation was executed by this research. Fixed source versions, file headers, links and failed retrievals remain in adjacent manifests. No complete physical accuracy PASS is claimed.
