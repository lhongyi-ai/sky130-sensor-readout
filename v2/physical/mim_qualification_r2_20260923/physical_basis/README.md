# CAPM physical basis: incomplete

The bounded source review confirms ordinary-metal data, not a complete validated CAPM thin-electrode/special-dielectric/edge/corner stack. M3 bottom height/thickness are 2.7861/0.845 µm and M4 4.0211/0.845 µm in the examined references. Ordinary NILD5 K=4.1 is not automatically the dedicated MIM dielectric value.

A public cross-section script contains capm_thickness=0.06 and capm_diel_thickness=0.04, but its author explicitly describes some dimensions as guessed. These visualization variables are not qualified process data and were not used to build ICT. Electrode sheet resistance likewise cannot uniquely determine thickness, bulk resistivity or temperature dependence.

Magic height entries and ordinary-metal coupling tables do not supply an applicable complete CAPM stack. No supported matching Quantus MIM package was obtained in the examined sources. This is a bounded search result, not a statement that no such data exists.

See `multiport_trial_spec.md` for frozen geometry, ports, independent references and uncertainty requirements. Status remains PHYSICAL_BASIS_INCOMPLETE; no EDA or field solve was performed by this research review.
