# CAPM physical and independent-reference review r3

All seven pages of the officially linked RCX Stackup Sheet were retrieved and frozen by retrieval time/content hashes. The pages cover model responsibility, ordinary-metal variation, ordinary vias, basic capacitance tables, extended data and ordinary/ReRAM layer R/C.

The responsibility table still describes an older M2/CAPM/via2 boundary. Ordinary layer/via tables have no applicable dedicated CAPM material entry. The4305-row extended table lacks a decoded format/CAPM binding in this review; keyword absence does not prove all its data unrelated, and undecoded values cannot generate MIM ICT.

The source notes supply useful ordinary-interconnect references. Official MIM regression tests validate functional model arithmetic but do not provide an independent matched peripheral multiport matrix. The Google Sheet has no immutable release version obtained here; retrieval date is not a process version.
