# 开源动态器件噪声资格探针（2026-09-10）

## 结论

**发现了不依赖 Cadence 的固有噪声引擎，但单管对照进一步确证了模型噪声不等价，不能用它直接验收当前 SKY130 ADC。**

同一固定镜像中已经安装的 VACASK `a9d8860929517499299b91a0300c0f8ff2ff4716` 支持由器件模型产生的瞬态噪声。此次完成的是它的最小物理／可重复性资格检查。没有下载、安装新软件，没有在 ADC 输入上加任意白噪声，也没有把连续 `.noise` 冒充时变噪声。

机器可读结果：[qualification.json](qualification.json)。其中 `adc_noise_qualified=false`、`full_chain_sndr_qualified=false` 是有意保留的真实状态。

## 已经实际做了什么

使用一个 10 kΩ 电阻与 1 nF 电容组成的最小 RC 电路，温度 27 °C，电流激励为零。电阻模型自身提供热噪声：安装源码 `devices/resistor.va` 中噪声功率谱密度为 `4 k T / R`，没有额外随机源。理论无限带宽总电压方差为 `kT/C = 4.1440179735e-12 V²`，对应约 2.036 µV RMS。

仿真持续 20 ms，舍弃最初 1 ms。分析前把自适应时间步波形插值到均匀的 100 ns 网格，避免把仿真器密集输出的时间点错误地当成更长的物理时间。开启噪声时设置 `noisefmin=10 Hz`、`noisefmax=1 MHz`；该引擎的白噪声算法与 flicker 的频率范围实现不同，不能把 `noisefmin` 简单当作理想砖墙高通。本 RC 检查主要针对热噪声。

| 对照 | 测得电压方差 / 理论 kT/C |
|---|---:|
| 关闭瞬态噪声 | 0 |
| ZOH，seed 11，6 倍过采样 | 1.05397 |
| 完全相同条件重放 | 1.05397，完整波形哈希相同 |
| ZOH，seed 29 | 1.03908，波形不同 |
| ZOH，12 倍过采样 | 1.01937 |
| SDE，6 倍过采样 | 1.04539 |

同电路的独立小信号噪声积分（10 Hz–1 MHz）为 `4.1009348933e-12 V²`，接近解析值。它仅作为这个线性时不变 RC 控制的交叉检查，不能推广成 SAR ADC 的噪声成绩。这里的 20% 物理量级检查门槛是引擎探针的门槛，不是放宽芯片规格；仅两个独立随机种子也不是统计精度认证。

全部输入电路、日志、原始波形和初始失败都在 `results/` 中。成功 RC 对照固定引用 `results/20260910T062307Z/`；不会靠挑选某个随机种子得出芯片 PASS。

## 为什么尚未直接运行 SKY130 ADC 的动态噪声

先搭建了一只 SKY130 `nfet_01v8`（W=2 µm、L=1 µm）的共源最小测试，包含电阻负载和电容。原始 ngspice 的工作点、小信号噪声、普通瞬态均运行完成，证明当前 PDK 与测试本身可用。普通 `.tran` 的输出基本恒定，小信号噪声却非零：两种分析不能混为一谈。

然后尝试使用已安装的官方 `ng2vc` 转换器迁移同一个器件。探针记录了以下逐步遇到的问题：

1. 转换器没有按被包含文件所在目录递归解析相对路径。
2. 某些模型选择编号写成 `54.0`，转换器直接 `int()` 解析失败。
3. ngspice 的控制命令在转换器一遍处理中被误当器件，故只转换硬件描述，后续分析应另写为 VACASK 原生语法。
4. 某些 `.param` 表达式在大括号后还有加法项，转换器按空格拆分后失败。
5. **最终的实质缺口：这份安装的转换器没有 MOS `M` 实例输出函数、没有 LEVEL 54 的 BSIM4 映射，也没有解析 SKY130 `.N` 尺寸分档的完整路径。**

前四项只做了语义保持的独立适配（文件查找、整数编号文本格式、分析与电路分离、表达式括号），没有删改工艺参数。第五项不能靠关闭报错或删掉晶体管绕过，因此本轮停在明确的迁移缺口。虽然 VACASK 带有可用于瞬态噪声的 `spice/bsim4v8.osdi`，这不等于 SKY130 标有 BSIM 4.5 的全部模型、分档、失配和乘数已被验证等价。

PDK 派生内容只允许写入容器的专用 `/tmp/sensor_noise_pdk_*` 临时目录；仓库保存转换脚本、路径和哈希，不保存整个 PDK 的转换副本。没有修改当前前端／ADC／数字源文件。

## 追加：绕开通用转换器，单只真实 SKY130 NFET 的数值对照

随后完成了更深入的有界适配，不再停在通用转换器的语法报错。`single_mos_numeric.py` 读取 ngspice 实际选中的 `xm:nshort_model.29`，明确报告原生实现为 **BSIM4v5，version=4.5**。从该 bin 逐项读取 349 个原模型显式参数及 14 个实例参数；不把未提供的默认参数全部强行设值，以免改变模型内部的 Given 标志。

- 所有参数在容器 `/tmp/sensor_numeric_bin_*` 中保存，仓库仅记录哈希。
- ngspice 查询返回的 `tnom` 是 Kelvin，写回模型卡时明确转换为 Celsius；器件几何查询已是米。
- `m` 依照官方模型源码明确映射为 `$mfactor`，保留电流、电荷及噪声缩放含义。
- `lintnoi` 在原模型中是显式零常数，但 native query 未暴露该字段，因此保留原字面值，没有删除。
- `level=54` 由模型实现选择表示；**version=4.5 明确保留，没有偷偷改成 4.8.3**。

先把完全展开的数值模型重新放回 ngspice，保持 BSIM4v5／4.5：DC 电流相对误差 `9.89e-13`、AC 复数响应最大相对误差 `1.35e-13`、噪声谱最大相对误差 `2.72e-13`。这证明此单一偏置点的参数提取和单位换算没有造成后续差异。

再把相同显式参数交给 VACASK：

| 测量 | 原 SKY130/ngspice | 数值参数/VACASK |
|---|---:|---:|
| 漏极电流 | 4.096583762 µA | 4.096583806 µA |
| AC 复数响应 | 参考 | 最大相对差约 2.11e-9 |
| 输出噪声 RMS，10 Hz–100 MHz | 162.476 µV | 139.794 µV |
| 相对原噪声功率谱 | 1 | 最低 0.4848，最大偏差约 3.144 dB |

**这是一个不能接受的噪声模型差异，即使 DC 和 AC 几乎完全重合。** VACASK 日志明确提示未知版本并回退 4.8.3；对应官方安装源码也只实现了 4.8.0–4.8.3。此次没有修改这条模型规则或删除报错参数来伪造通过。

同一个 VACASK 电路完成了 intrinsic transient noise 开／关演示：关闭时标准差约 `2.22e-16 V`，开启时约 `131.289 µV`。但这个开启结果来自不等价的模型，**不是合格的 SKY130 噪声结果**；20 µs 时长、10 kHz–100 MHz 噪声设置也不能拿来代替整条低频噪声谱或完整 ADC 精度验收。

证据固定在 `results/single_mos_20260910T063501Z/summary.json` 和 `numeric_equivalence.json`。所有成功与失败数据保留。现在的明确阻碍已由“转换器暂不支持”推进为“现成模型噪声不等价”：下一步需有匹配 BSIM4v5 的固有噪声实现，或经充分验证和用户审阅的模型迁移决策，不能只调整语法后继续宣称完成。

## 后续不依赖 Cadence 的具体通路

1. 先解决已证实的 BSIM4v5↔4.8.3 噪声不等价；再完成经过审查的 SKY130→VACASK 通用转换：尺寸分档、µm/m 缩放、MOS 乘数、模型版本、局部参数、失配随机变量生命周期必须逐项保持。现有单 bin 数值提取只适用于一个固定几何和标称实例，不能当作完整 PDK 移植。
2. 针对本项目实际使用的 NMOS／PMOS／LVT、真实电阻与 MIM，先逐器件对照 ngspice 的 DC、AC、静态噪声和电荷／电容；不能因为一个电阻测试通过就跳过。
3. 验证真正的 MOS 采样电路：长采集窗口后的采样噪声应接近适用的 kT/C，比较带宽、时间步和积分算法收敛，并检查关闭噪声、相同／不同种子。
4. 用真实动态比较器扫微小输入，估计决策概率和输入等效噪声；保留前一拍状态、重置、回踢与过载历史，不使用任意独立噪声源代替。
5. 完成现有 SAR 控制与新引擎的经验证连接，或经等价性验证的门级电路版本，然后再做完整 ADC／全链路相干采样动态验证。
6. 最终带宽不能随意截小来获得好看的 SNDR；必须提高 `noisefmax`、加密时间步并增加随机种子，证明结果收敛，同时计入噪声折叠、实际参考端和前端噪声。

按引擎当前时间步限制，若 `noisefmax=100 MHz`、过采样 6，最大时间步约 0.833 ns。仅 16,384 点、100 kS/s 的记录就需要至少约 1.966 亿个时间区间，还未计入启动和自适应细分。因此先做模块资格检查和方法收敛非常重要；这个估算是计算量说明，不是允许减少最终采样点数或噪声带宽。

此路线是**尚待实施的工程工作**，不是“物理上只有 Cadence 能做”。最终用户要求的 Cadence 原生设计与最终验证仍单列保留。

## 复现

在已有容器 `sky130-v2-resume-20260910` 中：

```sh
python3 /repo/v2/verification/noise_20260910/probe.py
python3 /repo/v2/verification/noise_20260910/build_report.py
python3 -m unittest discover -s /repo/v2/verification/noise_20260910 -p 'test_*.py'
```

探针一次只运行一个仿真进程，各轮输出新增时间戳目录。转换失败单列，绝不因此把 `adc_noise_qualified` 改为 true。`build_report.py` 对历史 RC 结果的引用是冻结的，若重新资格检查，应经审计更新引用，不能自动挑选最好一轮。
