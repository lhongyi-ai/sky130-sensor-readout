# PMOS DC 测试包 v0.1.0

创建独立 project1/tb_pmos_dc/schematic，任何同名 cell 已存在则停止。保留 NMOS 电路。此包只生成拓扑，PDK尺寸通过属性窗口设置。原 NMOS 生成方法已在用户环境运行，本次 PMOS 电路尚待 Linux 执行。

## 1 上传和生成

上传 project1_pmos_dc_v0.1.0.zip 到 ~/cadence_skywater/，Linux终端执行：

```bash
cd ~/cadence_skywater
unzip -n project1_pmos_dc_v0.1.0.zip
```

Cadence CIW 执行：

```lisp
load("/home/compute/l.hongyi/cadence_skywater/project1_handoff/m0_pmos_v0_1/create_tb_pmos.il")
```

预期 P1_PMOS_TOPOLOGY_CREATED；检查 CIW 诊断，生成完成不等于电路检查或仿真通过。报错保留原文，不删除同名 cell 反复重建。

Library Manager 打开 project1 → tb_pmos_dc → schematic，按 f 显示全部。

## 2 检查电路和填写尺寸

本次 PMOS 源极和体端接 VS=1.8 V；漏极接 VD=0.9 V；栅极接 VG=1.8-VSG。
因此 VSD=0.9 V，VSG从0升至1.8 V时，实际栅极从1.8 V降至0 V。变量是 VSG，不是 NMOS 中的 VGS。三只电源负端均接地。

M0应来自 sky130_fd_pr_main/pfet_01v8（普通阈值版本）。点击M0按q，在属性窗口依次修改：l=0.5u、fingers=1、m=1、fw=5u（若只允许改w则改w）。每项编辑后按Tab，确认最终w和fw均为5u。不要手填simW、simM和面积周长，让PDK回调更新。OK后重新查看参数。

点工具栏绿色对勾 Check and Save，确认无连通性错误。不要重新运行生成脚本。

## 3 打开并配置 ADE L

从当前 PMOS 原理图 Launch → ADE L。确认标题包含 tb_pmos_dc，不能在旧 NMOS 的 ADE 窗口中改配置。

- Variables → Copy From Cellview：VSG=0。
- 温度27°C。
- Setup → Model Libraries：保留学校已勾选的 sky130.lib.spice，section=tt；与成功 NMOS 测试相同，不重复添加。
- Analyses → Choose：dc、Design Variable=VSG、Start=0、Stop=1.8、Linear、Step Size=0.01、Enabled勾选。
- Outputs → To Be Plotted → Select on Design：点击M0最下方漏极引脚（本次PMOS漏极在下），按Esc。应为 /M0/D；只显示net名表示选成电压。

## 4 导出网表核对后运行

Simulation → Netlist → Create，再 Display。先把网表发回核对，不凭生成成功直接宣布通过。

预期电气关系（节点名可不同，下面只是核对示意，不是手写仿真替代网表）：

```text
parameters VSG=0
M0 (D G S S) pfet_01v8 w=5u l=500n ... m=1
VS (S 0) vsource dc=1.8
VD (D 0) vsource dc=0.9
VG (G 0) vsource dc=1.8-VSG
```

确认实际四端顺序D G S B、体源同节点、w/l/m、派生几何、tt、27°C和181点扫描一致；尺寸表达式等价写法可以接受。

核对后点击绿色 Run。PMOS漏极电流按流入端口为正的约定，正常导通时 /M0/D 应为负值。随着VSG增大，电流绝对值增大；不要求它等于NMOS的1.129 mA。不要用“电流为负”作为失败理由。

## 5 保存与回传

Session → Save State，名称 pmos_dc_tt_first。保留运行目录中的PSF数据，再回传本次网表、曲线截图和spectre.out。默认目录若沿用NMOS环境习惯，日志通常在 ~/simulation/tb_pmos_dc/spectre/schematic/psf/spectre.out；以实际运行路径为准。

通过条件：正常结束、无未解释模型/收敛错误、181个工作点、尺寸和连接正确、电流极性与趋势合理。仅本PMOS DC最小测试通过不代表失配、噪声、PVT、完整M0或OTA通过。
