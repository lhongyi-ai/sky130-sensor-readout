# project1 单管原生电路起步包 v0.1.0

本包是 M0 的电路生成与人工 ADE 验证入口，不是完整 M0–M5 设计包。只创建 project1/tb_nmos_dc/schematic；任何同名 cell 已存在就停止，不覆盖。脚本已做本地结构和连接几何检查，SKILL/PDK 实际运行仍未验证。首次运行可能暴露学校模型名或 Spectre 语法不兼容，保留真实错误。

## 1 上传和生成（Linux 终端 → CIW）

将 project1_m0_setup_v0.1.0.zip 上传到 ~/cadence_skywater/。

```bash
cd ~/cadence_skywater
unzip -n project1_m0_setup_v0.1.0.zip
```

在已经启动的 Cadence CIW 输入：

```lisp
load("/home/compute/l.hongyi/cadence_skywater/project1_handoff/m0_setup_v0_1/create_tb.il")
```

预期：CIW 出现 P1_M0_TOPOLOGY_CREATED。检查 schCheck 的诊断，不能只凭此文字认为电路检查通过。若报错，不重复执行、不删除现有 cell；回传 CIW 错误文字。部分电路可能已在内存或库中，须先诊断。

从 Tools → Library Manager 打开 project1 → tb_nmos_dc → schematic。按 f 适配显示。图中应有一个 M0、两个直流电压源 VD/VG 和三个地符号。M0 的源和体都接地；VD 正端接漏、负端接地；VG 正端接栅、负端接地。

## 2 填写尺寸（原理图窗口）

M0 初始保留 PDK 默认尺寸，尚不满足测试规格。选中 M0，按 q 打开器件属性。

依次把 Length/l 改为 0.5u，Number of fingers/fingers 设为 1，Multiplier/m 设为 1，Finger width/fw 改为 5u；每次编辑后按 Tab 使工艺回调生效。如果界面只允许编辑 Width/w，则在一指条件下将 Width 设为 5u，并确认 fw 同步为 5u。最终一指情况下 w 与 fw 都应为 5u。不要编辑隐藏的 simW/simM，不要自行填写面积周长。如果字段含义或显示单位不同，回传属性窗口，不猜单位。

点击 OK，重新按 q 确认尺寸保留。面积/周长由学校工艺回调更新，仍需在导出网表中核查。直接用数据库写入尺寸不会自动触发所有 CDF 回调，因此此版保留这一步人工操作。
参考：[Cadence 官方关于 CDF 回调的说明](https://community.cadence.com/cadence_technology_forums/f/custom-ic-skill/36448/skill-command-to-create-the-cell-view/1348670)。

分别查看 VD、VG：DC voltage 应为 0.9 和 VGS。执行 Check and Save。预期无连通性错误；有警告保留原文。

## 3 设置首次 DC（从原理图 Launch → ADE L；若只有 Explorer，使用对应测试编辑窗口）

- Setup → Simulator/Directory/Host：模拟器 spectre。每次运行使用新的项目结果目录，不覆盖前一次失败结果。可在 Linux 终端用 `mktemp -d ~/cadence_skywater/project1_handoff/m0_setup_v0_1/run_XXXXXXXX` 创建独立目录，将打印路径填入 ADE 的 Project Directory。
- Variables → Copy From Cellview：将 VGS 初值设为 0。
- Setup → Temperature：27°C；若菜单位置不同，在环境/模拟选项中确认实际温度。
- Setup → Model Libraries：新增下面报告中发现的模型候选，Section 为小写 tt：

```text
/project/engineering/cadence21/CDK/sky130_release_0.0.3/models/sky130.lib.spice
```

注意：报告只确认该文件存在且声明 tt，尚未证明学校 `nfet_01v8` 能在该入口中解析。保留学校自动配置的模型项并记录，不擅自删除或重复添加同一文件。若默认模型配置已存在，请先把该窗口内容回传核对。

- Analyses → Choose → dc：Sweep Variable 选 Design Variable；变量 VGS；Start=0、Stop=1.8；Sweep Type=Linear，步长 0.01 V。若界面按点数设置，应包含两端共 181 点。
- Outputs → To Be Plotted → Select On Schematic：点击 M0 漏端引脚选择电流，或选择 VD 正端电流。VD 正端电流通常为负，NMOS 吸收电流等于其相反数；不要据此误判。

## 4 先导出并核对网表，再运行

在 ADE 选择 Simulation → Netlist → Create，然后 Display。菜单版本可能略有差异。
参考：[Cadence 官方网表生成说明](https://community.cadence.com/cadence_technology_forums/f/custom-ic-design/42929/spectre-monte-carlo-simulation-without-ade-xl-license)。

检查并保存完整 input.scs（含层次子网表如有）：

1. M0 的节点顺序是 D、G、S、B，后两个都是地，漏栅分别连对 VD/VG。
2. 实际 w=5u、l=0.5u、m=1（等价科学计数值也可）；不能仍为默认 420n/150n。派生 ad/as/pd/ps 与宽度变化一致，没有沿用 420n 默认几何。
3. VD=0.9，VG 使用 VGS，DC 扫描0→1.8、0.01，温度27。
4. include 的模型路径及 section=tt；记录实际器件模型名。学校 CDF 默认是 nfet_01v8，不能擅自改成另一个模型名。

若这些项不明确，先回传网表，我来核对。只有连通性、尺寸配置正确才点击 Run。仿真报 undefined model/subcircuit、include 或语法错误就保存完整日志，不用替换成理想管，也不要修改 PDK。

成功标志：Spectre 正常结束、181个有效DC点、VDS恒定0.9V、栅压0→1.8V、电流随栅压总体增大、无 NaN/Inf。这里是环境与单管验证，不能代表 OTA/ADC 合格。
