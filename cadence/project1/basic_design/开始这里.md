# project1 基础设计整包 v1.0.4

本包在本地完成源码冻结、原理图与 symbol 生成器、基础测试台、执行入口、网表检查、结果分析和回传工具。**尚未在学校 Cadence 执行本包，不能把本地检查通过当成电路仿真通过。** 已完成的独立 NMOS/PMOS 测试保留在原 cell 中，不覆盖。

## 包里有什么

| 内容 | 本包提供 |
|---|---|
| 工艺电阻 | `p1b_tb_res`：`res_high_po_0p35`，默认单段 350 nm × 350 nm，体端接 VSS，0～0.1 V 的 I/V 测试 |
| MIM 电容 | `p1b_tb_mim`：`cap_mim_m3__base`，默认 4 µm × 4 µm、m=1，0.9 V 偏置下测量交流导纳与电容 |
| 工艺 RC | `p1b_tb_rc`：上述真实工艺 R/C 的小幅阶跃响应，用时间常数交叉检查 |
| 旧两级 OTA | `p1b_ota_legacy_r4` 原生 schematic 和 symbol，13 个 MOS 实例（M7 拆为两个并联单元），明确连接体端、偏置和全部端口 |
| OTA 测试台 | `p1b_tb_op/ac/loop/step/cm/psrrp/psrrm/noise/swing` 共 9 个 |
| 原有 PVT | 冻结的 13 条件，每个工作点、AC、环路、阶跃，共 52 项；不是新版系统的 45 点 PVT |
| 补充测试 | CMRR/PSRR 的传递函数、静态噪声、输出正向扫描，1/2/10/20 pF 负载，19 个共模输入点；标称 5 pF 已在 P01 中 |
| 证据 | 原设计网表、13 点历史汇总及全部 52 份 PVT 原始数据；旧失败完整保留 |
| 执行与回传 | `run.py`，每项独立目录；网表不符时不启动正式仿真；日志、波形、测量、版本与哈希一并回传 |

共 **13 个 cell、1 个 OTA symbol、87 个测试任务**。任务列表可用 `python3 run.py list` 查看。原理图使用器件、短导线和网络标签连接，便于逐个核对；不是导入的图片或单纯 Spectre 文本。

旧 OTA 保留原基准的理想 2 kΩ 串联 3 pF 补偿、理想 10 µA 外部参考、5 pF 并联 100 kΩ 负载。它的偏置由 MOS 电流镜生成，原设计没有需要替换的偏置电阻。工艺 R/MIM 的面积选择、精确实现 2 kΩ/3 pF、失配和版图属于后续元件替换与物理实现，不能在首次对照时偷偷改掉原基准。

本版依据 M8 实测回调，将 MOS 宽度明确适配至 0.01 µm 精度；原尺寸保持在 reference 中，逐管差异见 `尺寸映射.md`。这不是已验证的全工艺网格，其他器件仍须回调和网表核对。尺寸检查容差不放宽。

## 1. 上传与准备（Linux 终端）

把 `project1_basic_design_v1.0.4.zip` 上传到 `~/cadence_skywater/`。在终端依次执行：

```bash
cd ~/cadence_skywater
unzip -n project1_basic_design_v1.0.4.zip
cd project1_handoff/basic_design_v1_0_4
python3 run.py prepare
```

适配环境报告中的 **Python 3.6.8**，仅用标准库，不需要 pip 或安装软件。解压目录与 `project1` 库数据库分开。`unzip -n` 不覆盖已有上传文件；若以前已经放过同名版本，请先保留旧目录，不混合不同包。

`prepare` 创建 `site.json` 并打印一条包含你当前目录绝对路径的 CIW 命令。默认路径来自已有环境报告：

```text
OCEAN:   /project/engineering/cadence21/ic/tools/bin/ocean
Spectre: /project/engineering/cadence21/spectre/tools/bin/spectre
模型:    /project/engineering/cadence21/CDK/sky130_release_0.0.3/models/sky130.lib.spice
工作目录: ~/cadence_skywater
```

OCEAN 指向运行 Virtuoso 的 IC 安装，而不盲用 PATH 中另一套 ICADVM。这个绝对 OCEAN 路径仍须 Linux 首次执行确认；若不存在，工具会明确报环境阻塞，在 `site.json` 中修正路径即可，无需重新上传整包。模型入口的 TT 已由先前 NMOS/PMOS 实际运行验证，其他工艺角仍需本包实际执行。

```lisp

```

成功标志：CIW 出现 `P1B_ALL_CREATED`，包目录有 `created.txt`。Library Manager → `project1` 中出现本包的 `p1b_` cells。打开 `p1b_ota_legacy_r4/schematic` 和 `symbol` 即可查看。

生成器尝试调用学校 MOS 参数回调，更新总宽度、指宽、长度和扩散几何，免去逐个手填。它会检查请求尺寸是否被回调改变。**回调及 SKILL API 尚待本机型首次运行验证**；报错则停止，不默认采用错误尺寸。`cdf_values.tsv` 保存实际读回参数。

创建前检查全部目标名称；任何同名 cell 都会让生成步骤停止。重复 `load` 不覆盖已有电路。正常生成后直接运行后续测试，无需再 `load`。若生成中断，保留 cell 和 CIW 报错，不要删除库、不改工艺库；把错误文本、`create_status.txt`、`cdf_values.tsv` 回传，我据此修订。

## 3. 一条命令验证工艺 R/C（Linux 终端）

```bash
cd ~/cadence_skywater/project1_handoff/basic_design_v1_0_4
python3 run.py run --group passives
```

执行顺序：电阻 DC → MIM AC → 工艺 RC 阶跃。命令在后台调用 OCEAN 从这些原生原理图导出网表；本地编写的检查器核对网表后，才启动 Spectre。默认单任务串行，不申请并行作业。

每项结果位置：`runs/任务名/时间_随机编号/`。

| 文件 | 用途 |
|---|---|
| `status.json` | 工具运行状态与性能检查状态分别记录 |
| `native_netlist.scs`、`netlist_audit.json` | 原理图导出的原始网表及连线/尺寸核对结果 |
| `input.scs` | 实际执行输入；器件内容来自原生网表，附上本任务模型、参数和分析设置 |
| `spectre.out`、`log_audit.json` | 原始日志、退出码、正常结束检查及警告 |
| `psf/` | 实际 Spectre 原始结果，可在 ViVA 打开 |
| `*.csv`、`metrics.json` | OCEAN 导出的波形、实际测量和门槛判断 |
| `ocean_netlist.log`、`ocean_export.log` | 网表生成或结果导出故障诊断 |

成功要求：`status=PASS` 且 `performance_status=PASS`。电阻要求正阻值、近似线性，并与 CDF 标称值比较；MIM 要求正电容并比较 CDF 默认 34.6223 fF；RC 用阶跃时间常数核对。1%/5%/10% 是本包环境测试容差，不是工艺精度或芯片规格承诺。若默认模型与 CDF 数值不同，保留结果分析原因，不能为了显示通过而直接放宽。

## 4. 旧 OTA 标称四项（Linux 终端）

工艺 R/C 三项通过后执行：

```bash
python3 run.py run --group nominal
```

依次执行 `P01_op`、`P01_ac`、`P01_loop`、`P01_step`，均为 TT、1.8 V、27°C。共模保持 0.9 V。输出工作点包含每个 MOS 的电流、gm、gds、VDS、VDSAT；测量表同时保留与旧 ngspice 结果的差值。

AC：1 Hz～1 GHz、每十倍频 120 点；差分输入为 +0.5/−0.5 V 小信号，按实际差分输入归一化。环路采用原 1 GH/1 GF 断环条件，记录全部 0 dB 交越、方向及相位；不是只看第一处交越。

阶跃：0.8→1.2 V，延迟 1 µs，上升/下降各 20 ns，高电平宽度 2 µs，周期 5 µs，总时长 5 µs，最大步长 0.5 ns。沿用原 **20%～80% 最小二乘压摆率**及相对输入 50% 交点的 ±4 mV 建立时间。原始 13 点历史波形已用于检查分析程序的一致性，历史失败不变成新通过。

本包采用更严格 Spectre 数值容差；学校模型版本也与原开源 PDK 不同。因此结果差异必须解释，不能保证与历史结果完全相等。

## 5. 原有 PVT 与补充测试（Linux 终端）

标称核对后执行：

```bash
python3 run.py run --group pvt
python3 run.py run --group extra
python3 run.py summary
```

PVT 为原 P02～P13 的另外 48 项，P01 四项已在标称阶段运行。PVT 中电路性能失败继续记录其他条件；工具失败会停止，避免连续产生无效运行。`summary` 列出每个任务的所有尝试，未运行明确显示 `NOT_RUN`，并生成 `attempts.csv`，不会自动挑选每次最好的结果。

也提供统一入口 `python3 run.py run --group all`，适合首次流程已验证后的顺序批量执行。首次建议按上述三个分组，便于定位环境问题，无需另外上传文件。

CM/PSRR 测试输出传递函数，需与同频差分增益配对后得到抑制比。静态噪声导出值的单位需在 ViVA 首次核实。这些补充项显示 `REVIEW_REQUIRED`，不能直接作为完整验收通过；更不能替代 ADC 开关动态噪声、失配或版图后验证。

## 6. 中断、重跑与失败

已尝试过的任务默认跳过，包括失败，不会改写旧目录。例如某项修复后：

```bash
python3 run.py run --job P01_ac --retry
```

每次 `--retry` 都新建结果目录。若终端被关闭，未写入最终状态的目录保留原始日志；这种 `NOT_RUN` 不代表通过。不要手动把 `status.json` 改成 PASS。连线错误、参数错误、扩散几何异常会在 `netlist_audit.json` 或 `status.json` 中报错；未通过网表核对的电路不会被用作正式结果。

`status=PASS` 仅表示本项完成网表审核、Spectre 与结果导出。`performance_status=FAIL` 表示测得数据未达测试门槛。`ENV_BLOCKED` 表示工具、路径或原生网表生成受阻。缺少导出信号时保留 PSF 并报告失败，不填零、不制造测量值。

## 7. 一次打包回传

在同一 Linux 目录执行：

```bash
python3 run.py summary
python3 run.py collect
```

最后打印 `project1_basic_report_时间_编号.zip` 的完整路径。下载这个 ZIP 发回本任务即可。包含真实 PSF，运行较多时文件会变大；它不包含整套 PDK、规则或许可证。若生成阶段失败，还请把 CIW 中的具体错误文本一起发回。

## 已知边界

- 本包的生成器、OCEAN 网表路径行为、模型角、结果信号名、回调行为均需 Linux 首次执行验证；当前只完成本地实现与检查。
- 旧 OTA 对照为原理图级；不包含实际尺寸的工艺补偿替换版、版图、DRC/LVS/PEX，也未宣称它们通过。
- 当前包不迁移新版前端或 ADC，不更换数字标准单元库，不改变 `data_gain` 接口。
- 原生 cell 不被自动覆盖；版本冲突或回调报错需要保留现场并修订。本包能减少上传次数，不能保证未来无需修订。

## English technical summary

This bundle freezes the legacy Day 4 two-stage OTA and its 13-point PVT evidence. It provides native Cadence schematic/symbol generation, process resistor and MIM-capacitor benches, a process RC transient check, and 87 sequential simulation jobs. The legacy OTA retains the original ideal compensation and external bias reference for controlled comparison. Spectre runs use audited netlists exported from the native schematics. Every attempt retains its inputs, logs, raw results, tool provenance and measurements. Local checks are not Cadence qualification; all new SKILL/OCEAN flows remain pending execution in the school's installed environment.
