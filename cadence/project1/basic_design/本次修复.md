# v1.0.4：M7 超过单指宽度上限

学校实际回调明确报告：fw=72.2u 超过上限 50u，并被截为 50u。原生成器正确停止；接受被截小的 M7 会改变设计，不能跳过尺寸检查。

本版将 M7 明确拆成两个独立并联 PMOS：M7A 和 M7B，各 W=fw=36.1 µm、L=0.8 µm、fingers=1、m=1，总宽度仍为 72.2 µm。每个实例的 D/G/S/B 均分别接 VOUT/VBP/VDD/VDD。不额外设置倍乘2，以免重复计算。M3/M4 的已有并联单元保持不变；OTA 共13个实际MOS实例。

两个实例分别使用 PDK 回调计算扩散几何。按当前已核对的一指几何关系，面积总和保持一致，但每个扩散端的周长总和比单实例多0.53 µm。不能将这个拆分称为寄生完全等价；影响需在后续仿真对照中确认。

网表审核检查两个实例都存在、尺寸和体端正确；工作点分别导出，并为 M7 汇总 ids/gm/gds，饱和裕量仍逐管检查。任何漏掉 M7B、倍乘错误或缺失结果都会失败。所有生成目标 MOS 单指宽度现在均不超过50 µm；这个限制来自本次学校报错，不代表其他工艺规则已验证。

新 OTA 名称为 `p1b_ota_legacy_r4`，测试台引用同步更新。旧版本和诊断 cell 保留。

## 操作

上传 `project1_basic_design_v1.0.4.zip` 到 `~/cadence_skywater/`，在 Linux 终端执行：

```bash
cd ~/cadence_skywater
unzip -n project1_basic_design_v1.0.4.zip
cd project1_handoff/basic_design_v1_0_4
python3 run.py prepare
```

将打印的 `p1bRoot=... load(...)` 整行粘贴到 Cadence CIW。看到 `P1B_ALL_CREATED` 后，在新目录执行：

```bash
python3 run.py run --group passives
```

若有错误，回传 CIW 内容、新目录的 cdf_values.tsv 和 create_status.txt。不要删除旧 cell 或忽略参数截断。本包的本地检查不能替代学校实际运行。
